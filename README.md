# Gestion de Restaurant

> Projet académique — Licence 2 Informatique de Gestion | ENEAM 2026  
> Groupe : DJIDOHOKPIN Oluwatobi · GBO ANIANOU Vignon · HOUNTONDJI Béni · KAKPO Honoré · KLIKA Fortuné · SINDEDJI Marie Josée

---

##  Présentation

Ce projet vise à moderniser le processus de commande dans un restaurant,  
en remplaçant les échanges manuels (commandes verbales, addition manuscrite)  
par un système numérique fluide et fiable.

Il s'appuie sur une analyse AS-IS / TO-BE du processus existant,  
réalisée dans le cadre du cours **Analyse des Systèmes d'Information**.

---

##  Objectifs

- Réduire le délai de service de 35 min à moins de 20 min
- Éliminer les erreurs de commande (cible : moins de 1 sur 20)
- Automatiser la transmission des commandes en cuisine
- Accélérer la facturation (cible : moins de 3 min)
- Suivre les stocks en temps réel

---

##  Fonctionnalités prévues

| Module | Description |
|--------|-------------|
|  Consultation du menu | Affichage des plats disponibles avec prix |
|  Prise de commande | Interface numérique pour le serveur |
|  Gestion des stocks | Vérification et décrémentation automatique |
|  Transmission en cuisine | Envoi automatique du bon de commande |
|  Facturation | Calcul automatique et édition du reçu |
|  Suivi des performances | Rapport journalier des délais de service |
